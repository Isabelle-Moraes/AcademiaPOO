# AcademiaPOO

## Sobre a atividade

Este projeto foi desenvolvido como atividade da disciplina de **Desenvolvimento para Servidores I**.

O objetivo é aplicar conceitos de **Programação Orientada a Objetos** na criação de um sistema simples para representação e gerenciamento de alunos e professores de uma academia.

## Conceitos utilizados

Durante o desenvolvimento foram utilizados os conceitos trabalhados em aula:

- Classes e objetos
- Atributos e métodos
- Visibilidade
- Construtores
- Encapsulamento
- Getters e Setters
- Herança
- Sobrecarga de métodos
- Sobrescrita de métodos

## Projeto

O sistema possui as classes:

- `Pessoa` — classe base do sistema
- `Aluno` — representa um aluno da academia
- `Professor` — representa um professor da academia
- `AcademiaPOO` — classe principal responsável pela execução do sistema
